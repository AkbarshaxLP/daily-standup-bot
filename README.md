# Daily Standup Bot

Telegram бот для мониторинга ежедневных стендапов в видеочате.

## Что делает

- Отслеживает старт и конец видеочата в группе
- Фиксирует, кто и когда зашёл в звонок
- Считает время с **включённым микрофоном** для каждого участника
- После завершения звонка отправляет отчёт в группу
- Напоминает команде о стендапе за 5 минут (по расписанию)
- Показывает, кто **не пришёл** на стендап

## Как работает

Бот состоит из двух частей:

| Часть | Технология | Зачем |
|-------|-----------|-------|
| User Client | GramJS (MTProto) | Получает события участников звонка и статус микрофона |
| Bot | Telegraf | Отправляет отчёты, команды, напоминания |

> **Важно:** MTProto user client требует отдельного Telegram аккаунта (не бота), который должен быть **участником группы**.

## Установка

```bash
cd daily-standup-bot
npm install
cp .env.example .env
```

## Настройка .env

```env
BOT_TOKEN=       # от @BotFather
API_ID=          # с https://my.telegram.org
API_HASH=        # с https://my.telegram.org
PHONE_NUMBER=    # номер аккаунта-наблюдателя (+79001234567)
GROUP_CHAT_ID=   # ID группы (узнать командой /chatid)
ADMIN_IDS=       # ID администраторов бота через запятую (необязательно)
```

## Первый запуск (авторизация MTProto)

```bash
npm run auth
```

Введите номер телефона и код из Telegram. Сессия сохранится в `data/session.json`.

## Запуск

```bash
npm start
# или в режиме разработки:
npm run dev
```

## Добавление участников команды

**Вариант 1 — через файл** `data/members.json`:
```json
{
  "members": [
    { "telegramId": 123456789, "name": "Иван Иванов", "username": "ivan_dev" }
  ]
}
```

**Вариант 2 — через команду бота** (нужны права администратора):
```
/add 123456789 Иван Иванов
```

Узнать свой Telegram ID можно у бота @userinfobot.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/chatid` | Показать ID текущего чата |
| `/members` | Список участников команды |
| `/add <id> <имя>` | Добавить участника |
| `/remove <id>` | Удалить участника |
| `/lastreport` | Отчёт о последнем стендапе |
| `/testreport` | Тестовый отчёт (без реального звонка) |

## Пример отчёта

```
📋 Итоги Daily Standup
📅 четверг, 26 марта 2026 г.
🕐 10:00:05 – 10:22:40 (22 мин 35 сек)

✅ Присутствовали (3):
  • Иван Иванов — зашёл в 10:00:05, 🎙 8 мин 12 сек
  • Мария Петрова — зашла в 10:01:30, 🎙 5 мин 44 сек
  • Алексей Сидоров — зашёл в 10:03:10, 🔇 микрофон не включал

❌ Не пришли (1):
  • Пётр Козлов
```

## Расписание (UTC, по умолчанию для МСК UTC+3)

| Событие | Cron | МСК |
|---------|------|-----|
| Напоминание | `55 6 * * 1-5` | 09:55, пн–пт |
| Проверка опоздавших | `30 7 * * 1-5` | 10:30, пн–пт |

Изменить в `.env`: `REMINDER_CRON` и `LATE_CHECK_CRON`.
